# Demo Video

## 📹 LinkinAutomator Demo

The demo video (`demo/linkin-automator-demo.mp4`) showcases all features of LinkinAutomator in action.

### 🎬 What's in the Demo

- **Authentication**: Session restoration with cookies
- **Search**: Keyword-based profile search ("Recruiter")
- **Stealth Features**:
  - 🖱️ Bézier curve mouse movement
  - 📜 Human-like scrolling  
  - ⏱️ Random timing delays
  - 🎯 Random hovering over elements
- **Profile Interaction**: Navigate, scroll, find Connect button
- **Back Navigation**: Return to search results for next profile
- **Debug Logging**: See every action in real-time
